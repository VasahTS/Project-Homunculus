## Como usar (PC do Daniel), dentro da pasta `Homunculus2`
- **Jeito fácil (28/10):** clique duas vezes em **`Abrir Homunculus.bat`**: ele faz o `npm install` (rápido quando nada mudou) e abre o app com a versão mais nova do código. A janela preta precisa ficar aberta enquanto usa o app.
- **Para o testador / versões públicas (29/10, D-037):** `docs/PUBLICAR.md` — Actions → **Publicar versão**; o app instalado se atualiza sozinho (pergunta antes).
- **Como programa instalado:** clique duas vezes em **`Criar instalador.bat`** → espera (a 1ª vez leva de 10 a 20 minutos; depois, alguns minutos) → abre a pasta com `Homunculus_0.0.1_x64-setup.exe` → instalar. Depois o Homunculus abre pelo Menu Iniciar, sem janela preta. **A cada atualização do Claude, rodar o `Criar instalador.bat` de novo** e instalar por cima (sessões, personagens e chaves continuam: ficam na pasta de dados do app e no Gerenciador de Credenciais, não no programa). O Windows pode avisar "editor desconhecido" (o app não é assinado): "Mais informações" → "Executar assim mesmo".
- O app instalado e o `Abrir Homunculus.bat` usam **os mesmos dados**. Só preferências de tela (barra lateral aberta/fechada) são separadas.
- Abrir o app pelo terminal (jeito antigo): `npm install` e depois `npm run app`.
- Testes do núcleo: `npm test`.
- Bateria completa (o Claude roda antes de entregar): `npm run test:all` (no PC exige `npx playwright install chromium` uma vez — opcional).
