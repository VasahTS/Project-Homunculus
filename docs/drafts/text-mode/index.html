Text is a fourth choice in the editor's layout switch. It shows the whole card as one plain document: a fixed title per field, no boxes, no JSON, no quotes or \n. Find and Replace work across every field at once, like Notepad++. When you open it, the app keeps a copy called Before this edit, so Compare can show what you changed and put any change back.

What it is

The same card as the other layouts, shown as text. A change here shows up in Sheet, Tabs and Writer at once, and it saves like the rest of the app.

  • Fixed titles: click one for Open in Form, Copy this field, or (on greetings) Add another / Remove.
  • Empty fields hidden until "Show empty fields".
  • Macros like {{char}} get a soft outline.

Find & Replace

  • Every match is marked at once; the field titles say how many each one has.
  • Aa match case, W whole word, .* regex with $1. A broken regex says so and replaces nothing.
  • Replace All is one step: one Undo puts everything back.

Compare

  • Opening Text keeps Before this edit by itself; nobody has to make a copy.
  • Side by side, changes marked word by word, Put back on each one, or Put back all.
  • In the app it can also compare with Last saved, the Original import, the Main version or any History entry.
