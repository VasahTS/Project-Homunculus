Sidebar chat folders, and an Assistant that reads chats

Two parts from docs/UI-PLAN.md. The sidebar keeps 10 recent chats in a smaller, one-line row, with pins and folders. The Assistant reads chats, knows which screen it was opened from, and asks before it runs a test reply. Folders and menus in the first board can be clicked.
