Ctrl+S saves · edits carry across drafts

Three directions for Library → Characters → New / Edit. All three fix the same problems: the alternate greetings get a real editor, Save stays visible, every field shows its tokens, the Description shows its <sections>, and optional fields stop looking as important as the Description. Try typing, adding and reordering greetings, dropping a picture on the portrait.

A · Sheet

Identity on the left (picture, name, tags, In the Scene, lorebooks, token meter, export). Everything you write on the right, as sections with a jump bar.

  • Good for: seeing the whole card at once, like the Library sheet.
  • Greetings: list + editor, Edit / Preview.
  • Closest to today: smallest change in code.

B · Tabs

A compact header (picture, name, versions, Save) and one tab at a time: Character · Greetings · Prompt · Lore & Regex · About · History.

  • Good for: long cards; the Description gets the full height.
  • Greetings: a strip of cards, editor next to a live chat preview with swipe arrows.
  • Cost: fields are hidden behind tabs.

C · Writer

The card as one document in the reading font, with an outline on the left (fields, the Description's <sections>, each greeting) and settings on the right.

  • Good for: writing a whole sheet in Description with XML tags; the outline becomes a table of contents.
  • Greetings: inline blocks in the document.
  • Cost: three columns need a wide window.
